Prompt pour génération de sprites :

"Génère une collection complète de sprites pixel art 32 bits pour un jeu incrémental idle de centre de tri de colis, dans un style minigame rétro 32 bits (pixel art coloré, simple et facile à animer avec 4-8 frames par animation). Ambiance industrielle moderne : gris métallique, tapis roulants mécaniques, boîtes de colis colorées (rouge, bleu, vert), camions de livraison, employés en uniformes bleus avec casques. Vue top-down simplifiée, lisible à un coup d'œil, sans réalisme excessif. Les sprites doivent être cohérents, avec des couleurs primaires (#F4F6F8 pour fonds clairs, #FFFFFF pour éléments, #E1E5EA pour contours), et adaptés à une grille de jeu.

Fond du jeu (warehouse) : Crée un sprite de fond statique représentant l'entrepôt principal (vue top-down, grille 16x16 tuiles environ). Inclut : zone d'entrée (porte avec flèche entrante), zone scanner (machines rectangulaires avec lumières), aire de tri (tables avec boîtes empilées), tapis roulants (lignes droites et courbes), zone de sortie/chargement (rampes avec camions), camions garés. Ambiance dynamique mais statique : poussière légère, boîtes en mouvement suggéré. Taille : 512x512 pixels, transparent sauf pour les éléments solides.

Sprites des items (employés, scans, etc.) : Génère des sprites animés pour les éléments actifs du jeu. Chaque sprite en 32x32 pixels, avec 4-6 frames d'animation (marche, travail). Inclut :

Employés : Hommes/femmes en uniforme bleu, poussant chariots ou scannant (animations : marche, scan, poussée).
Scanners : Machines rectangulaires avec lumières clignotantes (rouge/vert), animation : lumière pulsant.
Chariots : Petits chariots à roues avec piles de boîtes, animation : roulage.
Camions : Véhicules industriels avec remorque, animation : chargement/déchargement (portes ouvrantes).
Colis : Boîtes carrées colorées (rouge, bleu, vert), animation : glissement sur tapis.
Sprites des upgrades : Crée des icônes/sprites statiques 32x32 pixels pour les améliorations achetables (employés supplémentaires, scanners plus rapides, tapis accélérés, chariots, camions). Style icône simple, avec tooltip visuel : par exemple, icône employé avec +1, scanner avec flèche vitesse, tapis avec roue dentée. Couleurs : vert pour bonus, rouge pour coût. Liste basée sur les drafts : employés, scanners, tapis, chariots, camions, entrepôts.

Sprites des skills : Génère des icônes/sprites 32x32 pixels pour l'arbre de compétences (branches : Gestion du personnel, Technologie de scan, Infrastructure de transport, Organisation du tri, Logistique d'expédition, Aménagement d'entrepôt, Résilience offline). Style arborescent : icônes circulaires avec symboles (personne pour personnel, œil pour scan, roue pour transport, boîte pour tri, camion pour expédition, bâtiment pour entrepôt, horloge pour offline). Couleurs : bleu pour actif, gris pour verrouillé. Inclut niveaux 1-5 avec variations subtiles (étoiles ou barres de progression).

Tous les sprites doivent être en PNG transparent, optimisés pour animation (frames séquentielles), et cohérents avec une palette industrielle (gris dominants, accents colorés pour les colis). Génère au moins 20-30 sprites au total, organisés par catégorie. Assure une lisibilité à petite échelle pour un jeu idle où le joueur regarde sans interagir constamment."
